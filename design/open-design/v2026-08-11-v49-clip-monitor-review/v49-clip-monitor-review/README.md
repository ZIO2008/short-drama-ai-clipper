# Version 49：原剧切片监视器播放与轻量审片

本交付物在 Version 48 静态原型上做受控修订，仅扩展 `screen-clip`。主文件为 `../short-drama-material-studio-v49-clip-review.html`；原 Version 48 文件未被覆盖。

## 打开与查看

1. 打开主 HTML，进入“素材生产 → 原剧切片 → 候选工作区”。
2. 监视器底栏提供源 PTS、候选相对时码、播放/暂停、循环、倍速与音量。
3. 倍速与音量分别在点击后打开贴近按钮的小浮层。
4. 右侧检查器先选择“源片 / 当前候选 / 前后审阅”，再单独使用四个边界微调按钮。
5. 点击“第 06 集”可查看媒体不可读监视器状态；它保留最后已知画幅与重新定位提示，不伪装为候选。

## 关键交互

- 默认：候选 C-01 已选中、监视器暂停、“当前候选”审阅模式。
- 前后审阅：说明固定为“从入点前 1 秒播放至出点后 1 秒”；只影响播放范围。
- 边界微调：入点前移、入点后移、出点前移、出点后移，每次 0.1 秒。
- 循环：切换后有清晰激活态，并在当前审阅范围内循环。
- 媒体缺失：显示真实监视器轮廓、最后已知画幅和“重新定位源文件”动作语义。

配套说明见 `handoff.md` 与 `reuse-matrix.md`；关键状态证据见 `screens/`。

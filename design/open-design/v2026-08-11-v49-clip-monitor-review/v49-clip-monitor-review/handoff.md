# 交接说明：Version 49 原剧切片候选工作区

## 新增控件

| 区域 | 控件 | 交互与语义 |
|---|---|---|
| 监视器底栏 | 源 PTS / 候选相对时码 | 等宽数字显示；候选相对时码以当前入点为零点。 |
| 监视器底栏 | 圆形播放 / 暂停 | 唯一最强播放动作；只影响当前审阅会话。 |
| 监视器底栏 | 循环 | 切换当前审阅范围的循环播放，具有 `aria-pressed` 激活态。 |
| 监视器底栏 | 倍速 | 点击后在倍速触发按钮正上方打开 0.75× / 1× / 1.25× / 1.5× 小浮层。 |
| 监视器底栏 | 音量 | 点击后在音量触发按钮正上方打开音量小浮层；滑杆不常驻。 |
| 右侧检查器 | 审阅范围 | “源片 / 当前候选 / 前后审阅”只决定播放范围。 |
| 右侧检查器 | 边界微调 | “入点前移 / 入点后移 ｜ 出点前移 / 出点后移”，每次 0.1 秒。 |

## 状态覆盖

| 状态 | 入口 | 预期表达 |
|---|---|---|
| 候选已选中、暂停 | 初始状态 | C-01 选中；播放按钮显示播放。 |
| 当前候选 | 初始状态 | 只播放当前候选范围，不修改候选边界。 |
| 前后审阅 | 点击“前后审阅” | “从入点前 1 秒播放至出点后 1 秒”；只改变播放范围。 |
| 循环开启 | 点击循环图标 | 图标进入激活态，并在该审阅范围循环。 |
| 倍速浮层 | 点击倍速图标 | 贴近按钮展开；选择项带选中态。 |
| 媒体不可读 | 点击第 06 集 | 保留 16:9 监视器和最后已知画幅提示；候选边界与播放控制均禁用。 |

## 运行时交互边界

- 播放、暂停、循环、倍速、静音只影响会话播放状态，不写入候选。
- 审阅范围只计算播放起止，不写入候选边界。
- 四个微调按钮才可写入当前候选，必须满足 `0 ≤ 入点 < 出点 ≤ 源片时长`，最短时长为 0.1 秒。
- 源媒体不可读时不可沿用上一个剧集的画面、时间码或候选数据。
- 倍速或音量浮层打开时，按 Escape 必须关闭浮层并将焦点返回对应触发按钮。

## 明确禁止变化

- 不改变 Version 48 应用壳、深色 token、主监视器优先级、双时间线顺序或候选池结构。
- 不修改剧目库、资产页、字幕资产、候选池、完成报告、设置页。
- 不加入波形、帧号、帧级步进、常驻音轨、多轨时间线、AI 日志、技术仪表盘或 P2 解说/TTS/旁白。
- 不使用“上下”、垂直加减或“±”表达视频时间方向。

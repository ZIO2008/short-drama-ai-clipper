# 短剧 AI 切片工具

一个本地运行的短剧切片辅助工具，面向剪辑师、短剧投手和个人创作者。它的目标不是替代剪辑判断，而是把“导入剧集、生成候选片段、人工微调、确认、导出”这条链路做得更快、更稳定。

## 适合谁

- 需要从短剧剧集中快速整理投流素材的人。
- 需要批量查看、微调、导出切片的剪辑师。
- 希望在本地电脑处理素材，不想把原视频上传到陌生平台的个人创作者。

## 当前能力

- 批量导入多集视频。
- 配置大模型和字幕识别 API。
- 生成候选切片。
- 在审片台播放、查看、微调开始点和结束点。
- 标记切片状态：待审、修改中、已确认、已导出。
- 导出全部切片、单集切片或当前切片。
- 桌面版支持原生目录选择。

## 当前限制

- 目前优先支持 Windows。
- 切片算法仍在迭代，质量不会保证每条都能直接投放。
- 不内置任何 API Key，用户需要自行配置 DeepSeek/OpenAI/字幕识别服务。
- 用户需要确认自己拥有素材处理和导出的合法权利。

## 普通用户怎么用

推荐从 GitHub Releases 下载最新版 Windows zip，完整解压后双击目录内的 `短剧AI切片工具.exe`。不要只复制 exe，程序需要同目录的 `resources/`、`python/` 和 `models/`。第一次使用建议先看：

- `docs/用户使用指南.md`
- `docs/隐私与数据说明.md`

## 开发者怎么运行

开发者可以 clone 仓库后本地运行。详细步骤见：

- `docs/开发者运行指南.md`

## 配置 API Key

本项目不会提供默认 Key。你可以在软件设置页填写自己的服务商配置，也可以复制 `.env.example` 为 `.env` 后手动填写。

支持的主要配置包括：

- `DEEPSEEK_API_KEY`
- `OPENAI_API_KEY`
- `TENCENT_ASR_SECRET_ID`
- `TENCENT_ASR_SECRET_KEY`
- `XFYUN_ASR_APP_ID`
- `XFYUN_ASR_API_KEY`
- `XFYUN_ASR_API_SECRET`

# 短剧投流素材生成平台

面向 Windows 本地操作者的短剧素材工具：管理分集、准备字幕、生成候选、人工审片、确认导出并回看完成报告。

## 下载正式版

请到 [v1.0.0 Release](https://github.com/ZIO2008/short-drama-ai-clipper/releases/tag/v1.0.0) 下载 Windows x64 ZIP。完整解压后双击 `01_启动素材平台.bat`，不要只复制一个 EXE。

首次需联网获取并校验两个视频组件；本地 PaddleOCR 与模型随包。自动候选需要使用者自己的文本分析服务，ASR/视频复核按需要配置；费用由服务商计算。程序不含作者数据或密钥。

本包未签名。独立电脑兼容性尚未验收；本轮完成本机隔离安装和最终包验证，具体边界见 Release 说明。云 OCR、解说/TTS/旁白未开放；爆点前置二创仍为受控本地模式。

## 基本工作流程

创建剧目 → 导入分集 → 导入字幕/本地OCR/ASR → 生成候选 → 人工审阅与微调 → 确认 → 显式勾选 → 导出 → 完成报告。

默认中文文件名和持久切片编号无需填写英文模板。原片按原路径引用，不自动复制备份；请自行保留原片和成果。

## 数据与升级

应用数据位于 `%APPDATA%\ShortDramaMaterialStudio`。升级前关闭软件，备份整个数据目录和原片并保留旧程序；同一Windows账户沿用已有应用数据，不要同时运行多个版本。旧 v8.x 工程不会自动迁移，新平台与旧版工具分别编号。

只分发原始ZIP，不要将首启下载补全后的程序目录重新打包转发。请保留随包第三方许可和来源说明。

## 源码构建

使用 `package.json` 指定的 Node 和 pnpm 环境，在仓库根目录执行：

```sh
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run build
```

开发运行使用 `pnpm run dev`。本地OCR的Python/Paddle环境、模型和打包后的运行时需要按 `tools/local-ocr/` 的脚本自行准备；它们是可再生依赖，不随源码提交。普通使用者直接下载Release包。

此分支是1.0.0应用源码的公开快照。`SOURCE-PROVENANCE.json` 给出与已验证构建输入逐字节相同的文件SHA256和发布ZIP身份；未上传本机工作历史、原始测试日志、素材、数据库或凭据。私有真实素材验收和本机scoped视觉证据不随源码提供；它们不能被描述为任意机器上自动通过的测试。打包发布还需自行准备OCR运行时及当前机器的验证证据。

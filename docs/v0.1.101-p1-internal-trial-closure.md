# 0.1.101 · 正式导出时间戳偏移修复

日期：2026-10-16。用户确认的 117.100—271.280 秒候选在 25fps 原片上导出，期望 154.180 秒，实际 154.280 秒，被既有精确校验拒绝。

## 根因与范围

正式 H.264/AAC 编码的 `-avoid_negative_ts make_zero` 在带音频和 B 帧时将输出时间戳整体后移。动态音视频夹具复现：期望 3.180 秒，旧参数输出 3.280 秒、视频首时间 0.080 秒；移除该参数后输出 3.200 秒、视频首时间 0 秒。参数含义见 [FFmpeg 官方格式选项](https://ffmpeg.org/ffmpeg-formats.html#Format-Options)。

生产改动仅删除正式编码分支的这项参数。准确后置寻址、指定时长、确认切点、帧率策略、预览 copy 分支不变。时长、首尾帧时间和源画面三重校验不变，25fps 既有时长容差仍为 0.09 秒。取消、失败清理和失败重试沿用既有机制；无页面结构、数据库 schema 或模型请求变更。

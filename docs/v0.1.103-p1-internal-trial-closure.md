## 交付

现有导出弹窗在 FPS/目录后、包装前增加文件命名输入。默认 `clip_{episode}_{candidate}`；支持固定文本、两位分集号 `{episode}`、候选编号前八位 `{candidate}`，系统添加 `.mp4`，同名自动追加 `_02` 等编号。显示示例和追加说明，取消与操作失败保留当前弹窗输入。

空值、超过 160 字符、路径/非法字符、未知或未闭合变量、Windows 保留名称（含上标数字设备名）、末尾点号及用户重复填写 `.mp4` 在预检前原位阻断。命名内容以 textContent 呈现，不作为 HTML。

审查发现原导出配置在任务内共享，另一候选会覆盖失败项重试时的命名。现于批次抢占成功事务内在既有 JSON 快照按候选保存配置，候选重试读取自身配置；任务重试按相同冻结配置合组，不同配置分别建批次。无映射的历史任务兼容原快照；已有映射却缺项时明确拒绝，不猜其它候选配置。没有新增表、IPC、数据库迁移、字幕控件或生成算法变更。

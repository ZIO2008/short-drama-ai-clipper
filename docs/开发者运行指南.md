# 开发者运行指南

## 环境要求

- Windows 10/11
- Python 3.10 或更新版本
- Node.js
- pnpm
- ffmpeg。建议安装到系统 PATH；公开源码仓库不提交 `ffmpeg.exe`。

## 安装 Python 依赖

```powershell
pip install -r requirements.txt
```

## 安装桌面端依赖

```powershell
cd desktop
pnpm install
```

## 启动本地服务

```powershell
python review_server.py
```

默认服务地址：

```text
http://127.0.0.1:8788/v8/
```

## 启动桌面壳

```powershell
cd desktop
pnpm start
```

## 生成 Windows 目录版

```powershell
cd desktop
pnpm dist
```

目录构建产物会输出到：

```text
dist-desktop/
```

如果你要发布给普通用户，需要把构建目录与 Python、ffmpeg、服务端资源一起组成完整 zip。不要只分发单个 exe；源码仓库也不要直接提交二进制文件。

## 本地配置

复制 `.env.example` 为 `.env`，然后填入自己的 API Key。不要把 `.env` 提交到 Git。

## 仓库不应提交的内容

- `.env`
- `review_projects/`
- `output/`
- `tmp/`
- `logs/`
- `dist-desktop/`
- `desktop/node_modules/`
- 用户视频、字幕、导出结果

## 开发注意

- 不要把真实素材放进仓库。
- 不要把真实 API Key 写进源码。
- 改 UI 前先确认是否影响监视器比例、时间线、导出链路。
- 改算法前先保留可复现样例和验证口径。

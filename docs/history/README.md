# 历史文档索引

本目录存放不再作为当前开发、设计或发布门禁输入的历史记录。归档只降低当前工作入口的噪声，不删除事实、哈希或历史证据。

- `closures/`：历史内部试点 closure；仅用于追溯当时的候选包与验证结论。
- `audits/`：旧 Phase、旧版本、字幕生产样本和 AI 能力的历史审计/试点报告；不是当前开发、候选或发布门禁。
- `research/`：已被现行合同覆盖的字幕/OCR 研究记录；只保留研究过程，不得恢复其中的旧时间轴或取样规则。
- `v48-legacy/`：Version 48 的对齐过程台账与未执行的视觉运行卡。当前设计基线以 `docs/current-design-baseline-v49-1-governance-2026-08-17.md` 的 V49 规则为准。
- `changelog/`：从根入口移出的完整产品变更流水；根 `Product-Spec-CHANGELOG.md` 只保留近期净变化和归档索引。
- `dev-plan/`：Phase 1–20 的完整历史开发计划；根 `DEV-PLAN.md` 只保留当前可执行 Phase、依赖顺序与冻结边界。
- `product-spec/`：2026-08-17 及以前的完整 Product Spec 原文；根 `Product-Spec.md` 只保留现行净需求、V49 唯一设计源和当前范围边界。
- `design-brief/`：2026-08-17 及以前的完整 Design Brief 原文；根 `Design-Brief.md` 只保留从 V49 实际 HTML 核对的当前视觉规范。
- `v48-legacy/` 同时收纳旧复用矩阵、迁移卡、差异台账、设计交付门禁和 Phase 17–20 审计；原 `docs/` 路径只保留短索引，避免旧链接失效或旧门禁复活。

归档文件不得重新作为当前设计源、视觉门禁或发布依据。需要追溯时，须同时读取文件自身日期和本索引。

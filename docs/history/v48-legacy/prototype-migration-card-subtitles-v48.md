## 三种识别方式增量（2026-08-05）

- 目标状态：设置弹层分别保存并截图 `asr-only`、`ocr-only`、`asr-ocr` 三种状态；同视口为 1440 x 900 和 1280 x 720。保存前静态夹具必须保持原型的模态尺寸、DOM 次序和页面滚动归属。

## OCR 区域作用域增量（2026-08-10）

- 迁移分类：屏内迁移。继承现有字幕识别设置弹层、校准页和唯一右侧证据滚动边界；只新增原型已有校准操作旁的作用域语义与当前集回显，不改字幕列表、详情三列、视频画框或页面滚动结构。
- 默认行为：识别设置为“自动检测字幕区域”时，不要求先保存剧目区域；每集由本地 runner 在本次识别中独立预检并使用临时区域，临时区域不写入 `subtitle_ocr_regions`。
- 作用域行为：从剧集详情打开校准时，确认保存为当前集 `episode_override`；从列表工具栏打开时，确认保存为可选的 `drama_default` 批量基线。当前集覆盖优先于剧目基线；清除当前集覆盖后恢复机器选择/剧目基线，不删除任何 OCR 轨或历史记录。
- 静态边界：不新增页面，不改变模态尺寸、DOM 顺序、校准监视器 16:9、单播放头或滚动归属；当前集标识只作为原型已有文案/摘要的数据槽。

## 字幕批量导入入口增量（2026-08-10）

- 原型来源：`design/open-design/v2026-08-06-subtitle-region-calibration/short-drama-material-studio.html`，SHA-256 为 `F3C24155514992D18E68629993F134115A0B1EAE02873145A6A4A2E529D796C4`。
- 迁移分类：屏内行为接入。继承已验收的 `screen-subtitles`、工具栏、原型按钮 `[data-subtitle-import]`、原型 toast 和独立 `.subtitle-list-scroll`；不新增按钮、弹层、列表列、滚动容器或页面。
- 绑定关系：原型已有“导入字幕”按钮调用本地文件选择，再依次调用 `previewSubtitlesByEpisode`、用户确认和 `importSubtitlesByEpisode`。预检只显示逐集唯一匹配与跳过原因；取消、无匹配、解析失败和超时不写入字幕资产。
- 数据边界：只替换原型已有 toast 的文案，按钮可见文字固定保持“导入字幕”。导入完成后仅派发 `subtitle-assets:changed` 刷新同一列表；不得关闭页面、改动详情弹层、识别设置、视频预览或滚动归属。
- 幂等边界：同一来源的迟到/重试请求由 `subtitle_assets` 的剧目、剧集、来源路径唯一索引收敛，不重复生成资产、轨道或 cue；同批多文件命中同一集时全部跳过并要求人工处理。

## 迁移分类

- 分类：屏内直接复制。迁移单位仅为 Version 48 的 `screen-subtitles`、查看画面模板、查看状态模板、识别设置弹层和 toast；不翻译为 JSX、不重绘。
- 外壳归属：字幕页头、工具栏、列表、详情弹层、设置弹层和滚动边界属于原型。原型应用壳、全局侧栏、全局顶栏、剧目库、素材生产和成果库不属于字幕迁移单元，禁止进入 iframe。
- 本轮已接两个行为：详情内的“字幕识别设置”复用现有六项设置表单；原型“查看画面”中可见的右侧证据区只读展示当前剧集的 ASR / ASR（导入）/ OCR 行。原型“查看状态”没有可见的右侧证据区，必须保持其原始空状态，不能为了读取证据而改成查看画面。
- 本轮新增左侧预览能力：原型 `r5-frame` 内展示当前剧集的本地源视频，时间码与剧集标识跟随真实播放位置；原型时间线改为单一播放头，点击、拖动与键盘定位只改变预览播放位置。不得保留范围条、入点/出点手柄、范围播放、候选写入或任何持久化。
- 左侧预览画框始终继承原型固定 `16:9` 比例，不得按源视频宽高改写；视频在画框内使用 `object-fit: contain`，完整显示竖屏或横屏源素材，剩余区域保留黑边。

## 原型边界

- 不得改变的结构与空间规则：剧目页头、工具栏、列表面板、样例行、文案、按钮和 `.subtitle-list-scroll` 的独立滚动边界均直接来自原型；剧目页头和工具栏固定可见。
- `查看画面`、`查看状态` 的入口及点击后内容从 Version 48 原型原文复制，真实行只决定显示哪一种入口；不得以 JSX、手写样式或真实媒体替换其结构。右侧证据区是唯一允许以真实只读数据替换内容的槽位。
- 第 12 集压力样本的入口及其点击后页面继续删除，不得出现在真实列表中。
- 真实剧集、批量导入、每集状态、一键生成字幕和每集删除属于列表能力，必须保留。删除只移除本软件内该集导入字幕，不删除 SRT、视频、ASR 或 OCR。
- 源视频不可读或浏览器媒体解码失败时，移除运行时视频并保留原型静态画面，同时在左侧既有剧集标识处如实说明；不得改动右侧证据、详情结构或列表状态。
- 运行时仅替换列表行的真实数据和操作节点；不得改变原型提供的列表容器、工具栏、文案、尺寸或 `.subtitle-list-scroll` 的滚动边界。

## 详情滚动裁决（2026-08-04 重新测量）

- 证据来源：原始 `short-drama-material-studio.html`，第 12 集压力态，Chrome 实测 `1440 x 900` 与 `1280 x 720`；截图见 `docs/design-evidence/v48/subtitle-migration-2026-08-04/prototype-stress-1280x720.png`。
- 弹层卡片 `.r5-modal-card` 为 `overflow-y: hidden`；弹层头固定。
- 弹层主体 `.r5-modal-body` 虽计算为 `overflow-y: auto`，但两套视口均 `scrollHeight === clientHeight`，不可产生滚动；不得为真实证据增加页面级或主体级滚动。
- 左侧 `.r5-sub-preview` 为 `overflow-y: hidden`，其画面与时间线固定。
- 唯一的长内容滚动容器是右侧 `#subtitleDetailAsset .r5-evidence`：压力态 `max-height: 420px`、`overflow-y: auto`，在两个视口均可独立滚动；真实数据只能填入该节点，不得替换节点、尺寸、层级或滚动归属。
- 真实长证据详情复用原型已有的 `data-subtitle-stress="true"` 标记，仅激活其既有的 `.r5-evidence` 420px 滚动规则；该标记不恢复第 12 集压力样本入口、文案或数据。
- 详情模板插入时必须位于 `#subtitleRecognitionSettingsModal` 之前，维持原型中“设置弹层覆盖详情弹层”的 DOM 层级；禁止用额外 `z-index` 修补。

## 静态夹具基线

1. Electron 字幕页从完整原型原文提取字幕迁移单元，在隔离 iframe 内呈现；iframe 内只允许一个 `#screen-subtitles`，不得存在 `.app`、`.sidebar` 或其它 `.screen`。
2. 分别在 1440 x 900、1280 x 720 验证真实剧集列表；导入后的 ASR（导入）、实际集数、状态和删除结果必须由当前剧目数据决定。
3. 字幕列表必须按真实行状态显示 `[data-subtitle-open-static="view"]` 或 `[data-subtitle-open-static="status"]`，并打开对应原型 DOM；不得出现 `[data-subtitle-open-pressure-sample]` 或任何第 12 集压力样本行。真实长证据详情可使用原型既有的滚动状态标记，但不得显示压力样本文案或数据。
4. 在长证据夹具中滚动 `.r5-evidence` 后，弹层头、左侧预览和时间线的几何位置不变；`.r5-modal-body.scrollTop` 必须仍为 `0`。
5. 列表与详情内的两个“字幕识别设置”入口都必须打开同一份原型设置弹层和同一套已持久化的六项字段。
6. 真实“查看画面”必须加载当前剧集的本地源视频；单一播放头跟随 `video.currentTime`，时间线点击、拖动、左右方向键、Home/End 只定位视频，不出现范围条或范围播放。

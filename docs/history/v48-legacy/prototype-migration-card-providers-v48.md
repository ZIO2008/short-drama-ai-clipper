# 原型迁移卡：供应商独立配置页 Version 48

## 范围

- 原型来源：`design/open-design/v2026-07-30-open-design-final/short-drama-material-studio.html`。
- 目标入口：设置 -> 能力供应商 -> `ASR 字幕识别`、`文本语义分析`、`视频理解复核`。
- 固定视口：`1440 x 900`、`1280 x 720`，Windows 100% 缩放。
- 本轮仅处理三张独立配置页 iframe 最外层的纵向滚动条；不处理“能力供应商”总页或其它设置页。

## 滚动边界

- 用户明确要求：三张独立配置页的 `html`、`body` 与 `#content` 不得产生整页滚动。
- 三张页面的 `.supplier-candidate-list` 与 `.supplier-draft` 保留原型已有的内部滚动和尺寸规则，不改动候选、筛选、卡片、字段、保存行为或文案。
- “能力供应商”总页继续沿用原有隔离边界，不因本轮改动改变其滚动行为。
- 该三页的 `#toast` 继续原样展示，但不接收鼠标事件，避免固定提示遮住右侧草稿底部的既有保存按钮。

## 验收

1. 三张独立配置页均无最外层纵向滚动条。
2. 候选清单和右侧草稿在内容超出其原型尺寸时仍由自身滚动容器承载。
3. 返回“能力供应商”总页后，其现有页面结构与滚动行为不变。

## 本轮目录数据

- DeepSeek 只作为“文本语义分析”的现有候选行写入，不新增总览卡、配置页、滚动容器或真实 API 执行路径。
- 预填使用官方 OpenAI 兼容基址 `https://api.deepseek.com` 和模型 `deepseek-v4-flash`；选择候选只填草稿，仍须用户显式保存，当前 P1 继续使用受控本地实现。
- 候选行仍由原型同一 DOM 模板生成；运行时桥接按候选显示名称找到目录项，不再依赖原型候选数组下标，避免新增候选后预填到错误供应商。

## Model Studio 安全展示边界（2026-08-14）

- 受影响原型：`v2026-08-05-asr-default-configuration/short-drama-material-studio.html` 的 ASR 供应商候选行。
- 原型文件保持只读；打包阶段仅在该文件的 `?raw` 导入边界将原始目录模型字段替换为 `null`，不改动节点顺序、布局、样式、事件或任何其它候选字段。
- 原始模型策略只由主进程在账号目录发现后选择。Renderer 和原型草稿只接收“等待自动选择”或“已自动选择兼容模型”这两个安全标签。
- 验收：原型 ASR 屏的结构/滚动规则维持本卡既有基线；生产 Renderer 构建不得包含该原始模型 ID，已自动选型的 ASR profile 必须显示为“已自动选择兼容模型”。

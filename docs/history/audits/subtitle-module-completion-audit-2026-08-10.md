# 字幕模块收口完成审计（2026-08-10）

## 判定边界

- 只覆盖云端 ASR、字幕导入、本地 OCR、三源详情与原剧切片时间轴门禁。
- 不纳入 P2 解说/TTS/旁白、剪映字幕识别独立工具、原始视频文件或未授权供应商执行器。
- 生产 SQLite 只读复核；没有输出密钥、请求体或原始云端响应。
- 发布视觉门禁单独记录：`audit:fidelity` 为 `completed=0 / incomplete=94`，所以可交付的是功能验证包，不是正式视觉候选。

## 逐项审计

| 目标 | 判定 | 当前证据 |
| --- | --- | --- |
| 1. 每集机器选区默认 | 已满足 | `LocalOcrSubtitleService` 自动模式向 runner 传递 `region: null`，不写人工区域；服务与 runner 测试覆盖，失败时保留真实原因。 |
| 2. 当前集覆盖优先级 | 已满足 | SQLite 的 `episode_override` / `drama_default` 约束、`SubtitleEvidenceService` 有效区域读取、校准桥接与实际 EXE 的保存/清除回归一致。 |
| 3. OCR 已知失败类型 | 已满足 | 第 44、48、68、73、77、79、80、82、84 集在临时目录用 `r8` 复测均成功且低于 420 秒；第 47 集明确为无稳定硬字幕带，未写入伪造轨。旧轨和失败记录保留。 |
| 4. 腾讯 ASR 真实句级时间轴 | 已满足 | 执行器固定官方 `ResTextFormat=3`，只消费 `FinalSentence/StartMs/EndMs`；第 44 集真实轨为 23 cue / 75 秒。旧 ASR 不补造时间码。 |

| 6. 可发现的安全批量导入 | 已满足 | 工具栏真实“导入字幕”入口、预览后确认、服务端复校验、取消/解析失败/重复/迟到保护均有桥接和服务测试；用户目录第 2-30 集 29 份 SRT 已只读一对一核验。 |

| 10. 静态原型边界 | 已满足 | 迁移卡 `docs/prototype-migration-card-subtitles-v48.md` 约束既有结构/滚动；新增覆盖行为由桥接接入。设计合同校验通过。 |

## 交付结论

字幕模块三条链路已具备本地生产试用所需的真实执行、失败事实、追溯和切片时间质量门禁。`release/verification/v0.1.52-p1-internal-trial-visual-unverified/` 是可追溯的功能验证包；因跨页面视觉基线未补齐，它不得标记为正式候选或对外发布包。

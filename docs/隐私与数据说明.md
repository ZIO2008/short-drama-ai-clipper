# 隐私与数据说明

## 本地优先

本工具优先在本地处理视频项目。导入的视频、项目状态、切片结果和导出文件默认保存在你的电脑上。

Windows 版的设置、项目指针、日志、诊断和缓存保存在当前用户的应用数据目录，不写入程序安装/解压目录。这样更新或重新打包程序时，不会把用户项目状态和设置带入发布包。

## 什么时候会调用外部服务

当你配置并使用以下能力时，工具可能会请求外部 API：

- 大模型：用于辅助判断切片、边界或质量。
- 云端字幕识别：用于把音频或视频转成带时间戳字幕。

具体发送给服务商的数据取决于你选择的功能和服务商接口要求。

## API Key

项目不提供任何默认 API Key。你需要自行配置服务商 Key，并自行承担调用费用。

请不要把 `.env`、截图中的 Key、日志里的 Key 上传到公开仓库或发给他人。

## 素材版权

用户需要自行确认自己有权处理、剪辑、导出和使用相关视频素材。本项目不提供版权授权，也不对素材来源和输出用途负责。

## 开源仓库边界

公开仓库只应包含源码、配置模板和说明文档，不应包含：

- 真实短剧视频。
- 真实字幕文件。
- 导出视频。
- 用户项目状态。
- API Key。
- 本地日志和缓存。

# 亲友同事分发计划

用户已确认0.1.108四入口切换正常，并于2026-10-19授权准备可供朋友、同事使用的分发包。此前本机替换阶段不包含跨机分发；本次单独补齐，不增加业务功能，不进行公开上传。

1. 核验当前程序身份：复用已验证0.1.108不可变候选，记录程序及资源哈希；不修改本机默认安装、真实数据库或旧版备用入口。
2. 准备Windows 10/11 x64解压运行包：本地OCR、中文首次使用说明、第三方许可与来源、校验清单。FFmpeg/FFprobe旧构建的完整对应源码未封存，因此ZIP不再分发这两个二进制；首次启动由接收者直接从固定上游获取，以已验收二进制SHA256验证，失败不启动、不接受替代版本。接收者使用自己的素材和服务配置，包内不含作者数据或密钥。
3. 从最终压缩包解压到独立位置验证：首次启动、空数据、配置入口、媒体导入、本地OCR及导出依赖。优先使用已有Windows测试虚拟机；区分实际跨机证据与本机隔离验证，不混称。
4. 独立审查分发范围、隐私、依赖与使用说明，修复后复核。通过后交付压缩包和SHA-256；未通过项明确记录，不能把内部候选直接称为已完成跨机发布。

完成标准：接收者无需开发源码、Node或外装Python即可启动；空账号不出现作者剧目；缺少自有模型配置时有正确说明；本地必要资源可用；最终文件可校验、可追溯。未购签名证书，需如实说明未知发布者提示，不要求关闭系统防护。

不包含：商业授权体系、自动更新服务器、云端协作、付费服务代充值、公开GitHub Release、旧版工程迁移、新的内容质量人工评审或字幕导出方式。

状态：用户要求的“先准备分享包”已完成；本机解压、隐私、首启补全/错误拦截、OCR空缓存、五项业务回归及独立审查通过。用户暂不方便解锁Windows虚拟机，独立电脑实际运行验收仍待完成。结果与文件哈希见2026-10-19-peer-distribution-result.md。0.1.108原有内部验收保持原结论，新增分发证据独立记录。

# 1.0.0 标准EXE安装包补正

状态：本轮已完成并公开交付，结果见2026-10-26-exe-installer-result.md；以下是保留的实施范围，不是未执行队列。

用户指出启动入口应为EXE。此前免安装ZIP+BAT不等于用户期望的常规Windows安装方式；本轮补齐NSIS安装EXE及桌面/开始菜单快捷方式，快捷方式直接指向软件EXE。

## 范围与完成标准

1. 复核已验收1.0.0 ZIP、候选及现有dir打包配置；更新源需求和发布说明。保持业务程序1.0.0原始字节，新增安装外壳，不覆盖已发布ZIP、不改正式数据库或日常入口。
2. 复用electron-builder现有NSIS目标与--prepackaged功能。生成独立Setup-x64.exe；安装向导可选目录、创建快捷方式和卸载入口。不要求用户手动解压或运行BAT。
3. 两个视频工具仍不随安装包重新分发。安装过程中以隐藏的系统PowerShell从固定上游下载并校验；失败/超时不得显示安装成功，并移除本轮快捷方式，允许重新运行安装器。安装成功后软件EXE可直接启动，无BAT入口。
4. 原应用、OCR及第三方许可从已验收ZIP提取并逐文件验证；只添加安装依赖脚本/中文说明，不改app.asar/原EXE。复用原业务证据，只补安装、快捷方式、真实安装后闭环、失败阻断、卸载保留数据及隐私/签名检查。
5. 使用隔离目录/数据进行本机安装测试，保护已有快捷方式和卸载信息，不把测试当跨电脑验收。fresh两阶段审查通过后，给现有v1.0.0 Release增加新EXE及独立校验/说明，更新首选下载入口；不覆盖原附件或移动v1.0.0标签。

本轮只改变安装交付方式，appVersion仍1.0.0，安装包制备修订setup-r1。独立电脑验收继续按用户决定暂缓；未签名如实说明。

# 正式导出时间偏移定点修复卡

用户失败：确认范围 117.100—271.280 秒，期望 154.180 秒，输出 154.280 秒；源帧率 25，配置为正式导出、原质量、跟随源帧率、无字幕/包装。正式编码分支实际使用 H.264/AAC。

复现：带 AAC 音频与 H.264 B 帧的 25fps 短夹具，确认 0.100—3.280 秒，原参数 `-avoid_negative_ts make_zero` 输出 3.280 秒、视频首时间 0.080 秒；默认 MP4 时间处理输出 3.200 秒、视频首时间 0 秒、音频 3.180 秒。原参数给输出引入整体偏移，错误恰为 0.100 秒。FFmpeg 官方说明该选项会统一平移全部输出时间戳：[格式选项](https://ffmpeg.org/ffmpeg-formats.html#Format-Options)。

修复范围：正式重编码分支去掉不必要的 make_zero，使用准确后置寻址与指定时长、MP4 默认时间处理。预览 copy 分支不变，保留既有时长容差、首尾帧时间和源画面检查；不改确认切点、不改变帧率策略、不放宽门禁。

执行与验收：真实音视频夹具先复现失败再验证成功；对当前失败候选的完整数据库只读快照在隔离库导出，核验时长、首尾帧、源文件和正式库哈希；原有取消/失败清理/重复导出回归；类型、构建、完整与包级验证及独立审查通过后，以新版本更新默认入口。隔离导出只处理用户这次明确选择的候选，不做全剧批量导出。

# 0.1.108 · 四入口切换闪烁修复

2026-10-19，本机维护更新。用户反馈字幕资产、候选工作区、全部候选、完成报告每次进入会闪一下；只修复这四入口交接，不新增业务功能、字幕方式、人工内容质量或P2。

## 原因与修复

真实隔离应用逐帧复现：旧页面先卸载，iframe结构准备期间出现约80–140ms不可见窗口；工作区/池初次IPC读取还短暂显示加载状态。没有将隐藏节点里的原型文字误当作可见旧版页面证据。0.1.107实际安装包的新fast回归失败于真实hidden/not-ready帧，不依赖缺少新增协议字段。

四入口现用浏览器原生View Transition保留旧画面，提交新目标后等iframe可呈现再直接交接，禁用该次交接默认淡化。三个业务桥只新增初次读取成功/失败信号；最多额外等250ms，慢读取继续显示原有真实加载，失败仍显示真实错误。初次iframe从未load时3秒显示既有错误/重试，原生等待3.6秒上限；超时、卸载、连续请求及API缺失/同步异常均有取消或回退。

原型的本地导航演示处理器会先于普通document监听执行；已知真实路由改为window capture，生成等业务动作仍放行。没有常驻第二个可操作页面、缓存旧业务数据或保存生产用户快照。最终原型HTML/CSS、布局、字幕数据、候选边界、IPC合同、数据库和导出服务均未变。

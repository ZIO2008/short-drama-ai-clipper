# 0.1.98 · 自动利用局部字幕证据

日期：2026-10-16。解决有 OCR/ASR 字幕、但局部空档导致整集不能生成候选的问题。用户明确要求识别后不再逐段人工确认，SUB-ASR-006 已相应修订。

## 行为与边界

- 自动按超过 20 秒的无锚点间隔分区，利用区间内合格的原始 OCR/ASR/已核验导入 cue。ASR 单条超过 20 秒仅排除该条；无需补一份导入字幕才能继续。
- 来源、ASR 官方元数据、非法及越界时码、未闭合冲突的拦截仍有效。候选不跨无合格证据支撑的长空档；不补造时间码，不自动重跑识别。
- 预检和冻结证据包使用同一局部资格 helper；逐 cue、逐事件记录 A/B/C/D，而非把整条轨道升级。新证据包使用 evidence-v6，旧冻结快照及历史导出继续按原身份和范围核验，不重写历史成果；无数据库 schema 变更。
- 无镜头/场景证据时不读取整集帧 PTS；存在场景证据时保留其 PTS 和源指纹验证。

# 发布与演示指南

## 发布原则

- 源码仓库只放代码、配置模板和文档。
- Windows 完整目录 zip 不提交到源码仓库，只作为 GitHub Release 附件发布。
- 不上传真实短剧素材、真实字幕、导出视频、API Key、本地日志和缓存。
- 第一版公开发布以 Windows 桌面版为主，不承诺 macOS/Linux。

## Release 附件建议

每个正式版本建议包含：

- `short-drama-ai-clipper-windows-x.y.z.zip`
- `short-drama-ai-clipper-source-x.y.z.zip`
- 可选：一张首页截图、一张审片台截图、一张导出页截图

不建议包含：

- 项目源码压缩包之外的重复源码。
- 真实测试素材。
- 用户配置文件。
- 历史开发报告。

## Release 说明模板

```markdown
# 短剧 AI 切片工具 x.y.z

## 适合谁

剪辑师、短剧投手、个人创作者。

## 这版能做什么

- 导入多集短剧视频
- 配置自己的大模型和字幕识别 API
- 智能生成候选切片
- 人工微调开始点/结束点
- 确认后导出 MP4

## 下载使用

1. 下载 `short-drama-ai-clipper-windows-x.y.z.zip`
2. 解压到一个普通目录
3. 双击 `短剧AI切片工具.exe`
4. 进入设置页配置自己的 API
5. 导入视频后开始切片

## 注意

- 不内置任何 API Key
- Windows 包内置 Python 和 ffmpeg，所以体积会明显大于源码包
- 不要把 exe 单独移出解压目录
- 请确认你有权处理和导出素材
- 算法质量仍会继续迭代，导出前建议人工检查
```

## 演示流程

演示不要讲内部算法细节，按普通用户视角走：

1. 打开软件。
2. 进入设置页，展示 API 配置入口。
3. 新建项目。
4. 导入 1-3 集视频。
5. 选择剧集，点击智能切片。
6. 打开一个候选切片播放。
7. 拖动开始点或结束点。
8. 点击确认可用。
9. 导出当前切片。
10. 打开导出目录，确认生成 MP4。

## 公开前检查

- README 能讲清楚工具是干什么的。
- 用户指南能让普通用户知道下一步点哪里。
- 开发者指南能让开发者 clone 后启动服务。
- 隐私说明能解释素材、API Key、云服务边界。
- `.gitignore` 已排除素材、导出、缓存、日志、密钥、构建产物。
- 干净环境首次启动不会读取旧项目状态。
- 上传入口、设置入口、切片入口、导出入口至少做过一次冒烟测试。

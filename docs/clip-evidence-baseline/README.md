# Phase 18 证据治理验收基线

本目录只保存版本化场景卡和合成/隔离夹具合同；不存放用户素材、用户数据库、密钥或隐藏验收媒体。

## Baseline v1

`manifest.v1.json` 固定列出 6 集公开开发集和 2 集隐藏验收集的隔离路径、场景卡、SHA-256 与历史结果引用；`pnpm run verify:clip-evidence-baseline` 只核验清单、路径隔离和指纹，不读写用户目录或数据库。

2026-08-13：用户已授权将现有真实剧集的 8 集只读副本用于内部开发验收。副本位于清单 `mediaRoot` 指向的隔离目录，已登记实际 SHA-256；原始媒体仍留在用户源目录，不上传、不进入源码或安装包。通过指纹校验只代表基线文件和路径完整，不代表 CLIP-032 的场景证据、候选质量或视觉门禁已经完成。

- `scene-cards.md`：公开开发场景的允许/禁止结论与证据要求。
- 隐藏验收集只保存在隔离验证存储，使用相同的场景卡字段，不进入源码、安装包或用户任务。
- 自动化回归使用内存 SQLite 与临时 FFmpeg 片段，覆盖候选不越权、blocked 不发布、源 PTS 可解析和任务快照可追溯。

任何卡片或夹具变更必须创建新基线版本，并保留旧版本结果；不得替换历史样本以掩盖回归。

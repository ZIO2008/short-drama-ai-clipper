# Baseline v1 场景卡

| 场景 | 必需证据 | 预期 |
| --- | --- | --- |
| OCR/ASR 时间一致 | 通过质量门禁的 OCR、ASR 和可解析 PTS | 可生成；起止和核心事件均回链 A 级文本证据。 |
| 导入来源未知 | `reference_unknown` 导入轨 | 阻断；恢复入口为字幕资产。 |
| 无字幕动作 | B 级 PTS 场景锚点 + 受限视频复核 A 视觉事实 | 可生成；原场景锚点保持 B，视觉 claim 回链独立 A 事实。 |
| 视频复核不成立 | B 级场景锚点 + `unsupported` / `unclear` 复核 | 阻断；恢复入口为素材资产。 |
| OCR/ASR 冲突 | 未闭合时间冲突 | 阻断受影响区间，不阻断无关合格区间。 |
| 接缝不清 | 连续核心单元及其前后保护上下文 | 只扩展一次相邻完整单元后重分析；仍不清即阻断。 |
| 队列恢复 | pending 与 interrupted running 任务 | 重启仅领取 pending 首项；running 不重放，且 checkpoint 保留原因、ETA 与槽位。 |

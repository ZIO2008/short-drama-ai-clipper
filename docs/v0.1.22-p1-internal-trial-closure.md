# v0.1.22 P1 内部试点闭环记录

日期：2026-07-29
范围：以 v0.1.21 的 Open Design 基线与 P0/P1 内部试点范围完成当前工作树核验；P2 解说、TTS、旁白保持冻结。

## 本轮修复

- `RemixExportService` 仅接受 `ai_remix` 草稿导出。历史 `ai_narration` 草稿会在创建文件或成果记录前被拒绝；`remix-export-service.test.ts` 覆盖该回归。
- `p1-remix-workflow.spec.ts` 补充 P1 二创与审核时间线的 1440×900 / 1280×720 截图、窄视口关键控件可操作性、公开能力列表不含 `tts`、preload 不暴露 `createNarrationTask`。
- `docs/design-evidence/v0.1.21/` 已归档四张 P1 双视口截图；复用矩阵和默认桌面审计同步记录。设置页和任务中心的隔离数据库内容按可解释的数据变体审计：不把原型中的演示剧目、任务、时间和通知当作生产默认数据。数据变体仍受 `0.50` 变化像素比例与 `25` 平均 RGB 差的错配包络约束，越界会使审计失败。创建剧目弹窗则在原型终态截图与生产截图之间，对固定 `620×534` 弹窗本体做严格像素对照；背景数据不参与该比较，未修改严格像素阈值规避差异。

## 真实行为接口与不变量

- 复用 `OriginalClipWorkspaceRuntimeBridge`、`clip-workspace-media-session` 和现有 desktop IPC；不改数据库 schema、供应商配置、密钥或导出流程。
- 保持 CLIP-008：分集切换原子同步，时间线定位不写候选，候选时间线左右键每次 1 秒，只有右侧四个 0.1 秒控件可修改边界。
- 保持 CLIP-045：只解码当前源分集，真实 PTS 为权威播放位置，候选相对时间只用于审阅显示。
- 空、加载、媒体不可读和已选候选必须保持独立 V49 状态；不能因真实数组为空或媒体可读性而折叠成旧布局。

## 视觉证据与完成条件

- 每个目标状态已在 1440×900、1280×720、100% 缩放下采集 V49 原型渲染和 Electron 实际图；两张图的路径、SHA-256、比较区域、受控差异与接受结论位于 `docs/design-evidence/v49/screen-clip/`。
- 静态结构与真实行为均已复核；视觉接受只覆盖本卡的三种状态。截图、DOM 断言、单测或编译不替代未授权屏幕的视觉验收。
- 完成前必须通过独立代码审查、受影响单元/集成测试、类型检查、构建和 current E2E 受影响路径；不打包或发布。

# 用户使用指南

## 一句话说明

这个工具用于把短剧剧集导入本地，生成候选切片，然后由你人工微调确认，最后导出需要的视频文件。

## 安装与打开

1. 从 GitHub Releases 下载 Windows zip。
2. 完整解压到普通文件夹。
3. 双击文件夹内的 `短剧AI切片工具.exe`。

不要只把 exe 单独复制到其他位置；同目录运行资源缺失时软件无法正常启动。

## 基本流程

1. 打开软件。
2. 进入设置页，配置大模型和字幕识别 API。
3. 新建项目或打开已有项目。
4. 导入一批剧集视频。
5. 选择要处理的剧集，点击智能切片。
6. 在审片台播放候选切片。
7. 调整开始点和结束点。
8. 点击确认可用。
9. 到导出区选择导出全部、导出单集切片或导出当前切片。

## API 配置

工具不提供默认 API Key。你需要使用自己的服务商账号配置：

- 大模型：DeepSeek 或 OpenAI。
- 字幕识别：腾讯云、科大讯飞、OpenAI Whisper API 或本地 Whisper。

如果没有配置字幕识别，智能切片可能无法正常完成，因为切片需要字幕和时间戳作为基础输入。

## 切片结果怎么理解

切片结果是候选素材，不代表每条都能直接投放。建议你至少检查：

- 开头是否完整。
- 结尾是否自然。
- 有没有把一句话切断。
- 是否保留了冲突、反转、情绪或信息点。
- 导出前是否已经确认可用。

## 导出说明

- 导出全部：导出当前项目里已经确认可用的切片。
- 导出单集切片：只导出当前剧集已确认可用的切片。
- 导出当前切片：只导出当前选中的一个切片。

导出的文件会保存到你选择的导出目录。

如果素材名以明确剧集编号开头，工具会保留来源信息，例如：

- `01（戏后）.mp4` → `第01集_戏后_切片01.mp4`
- `01（戏前）.mp4` → `第01集_戏前_切片01.mp4`
- `02.mp4` → `第02集_切片01.mp4`

无法明确识别的文件名会继续使用导入顺序，不会强行猜测。

## 常见问题

### 为什么切片质量不一定稳定？

短剧切片不是简单按时间均分。它需要判断对白、情绪、冲突、场次和出入点。当前版本已经跑通完整流程，但算法还会继续迭代。

### 为什么需要我自己配置 API？

因为不同用户有不同服务商账号和费用预算。项目不会内置任何默认 Key，也不会替用户承担 API 费用。

### 我的素材会上传到哪里？

视频素材默认在本地项目目录里处理。只有你启用云端字幕识别或大模型能力时，相关音频、字幕文本或片段信息才可能发送给你配置的服务商。

## 原型目标状态

1. 字幕识别设置内的“未校准”状态：显示“字幕区域校准”和“开始校准”。
2. “智能生成字幕区域”状态：竖屏代表画面、智能候选框、候选置信度、时间标记、`重新检测`、`手动框选`、`确认区域`。
3. “微调字幕区域”状态：区域边框、四角控制点、可拖动调整提示、时间轴定位。
4. 确认后的设置状态：显示“已校准”、坐标摘要、区域缩略图、“应用于本剧全部剧集”和“重新校准”。

## 结构所有权与允许替换

- 原型所有权：`subtitleRecognitionSettingsModal` 内的字幕识别设置内容与 `subtitle-calibration-view` 状态内容由本次原型拥有。
- 已接入的数据槽：当前剧目的已确认区域坐标和保存状态；确认后调用既有 `setSubtitleOcrRegion(dramaId, null, region)`，重开设置时调用 `getEffectiveSubtitleOcrRegion(dramaId, null)`；按 `sortOrder` 的第一集、其时长和当前播放位置。
- 已接入行为：代表视频画布为可见的黑色横向 `16:9` 监视器，竖屏视频按 `contain` 显示且不保留承载层边线；真实视频预加载，`canplay` 后暂停定位第 1 秒以展示首张真实内容，点击整块监视器可播放/暂停。框选坐标层按真实视频的实际显示尺寸动态对齐。第一集不可读时如实保留这一选择和失败状态，不改选其它集。点击时间轴定位真实视频，播放位置同步真实时间码，桥接统一维护拖动/缩放后的坐标并确认保存。
- 候选检测边界：当前没有可进入产品的检测器。运行时不得展示原型固定候选/时间标记；“重新检测”只能提示未接入，不能重置演示状态或伪称检测成功。
- 真实数据不得改变：原型容器尺寸、视频比例、区域框坐标系、按钮顺序、时间标记布局、模态滚动归属、设置字段顺序、字幕资产列表、其它页面导航。

## 明确边界

- 本次只做字幕区域校准，不接 OCR 识别、不生成字幕、不上传候选帧、不接供应商、不改 ASR、导入、删除、剧集列表、查看画面、查看状态、压力样本或右侧三源对照。
- 区域按剧目保存并应用于该剧全部剧集；本期不做逐集区域覆盖、不做跨剧复用。
- 区域外的人名、身份条、地点/时间牌和场景文字不进入本次 OCR 字幕区域；未来剧情辅助证据另立需求。
- 区域内的对白、剧情提示以及逐字/逐词/逐短语字幕均保留；不得以词义判断是否为标题或场景文字。`未完待续` 的窄排除规则不在本次静态迁移中实现。

## 静态夹具验收

- 固定视口：`1440 x 900`，浏览器缩放 `100%`，Electron 窗口使用同一视口。
- 验收顺序：未校准 → 智能候选 → 手动微调 → 已确认 → 重新校准。
- 每个状态必须保留 Open Design 原型截图与 Electron 实际截图；先验证 DOM 结构、视频比例、模态边界、滚动容器、区域框位置和按钮顺序，再允许接入真实数据。
- 任一状态出现原型与工具不一致时，停止在静态夹具修复，不以 CSS override 或旧组件补丁掩盖差异。

## 数据与 DOM 所有权

- Main snapshot 保存模型已选的 beat、purpose、context、narrative event/state、seam、claim kinds、复核状态、目标时长与偏离理由；不保存或展示思维链、提示词、A/B/C/D 或供应商原始响应。
- `listClipCandidates()`只返回受控 inspector DTO；renderer 不读取数据库 JSON、不推导资格、不猜测秒数。
- `.r5-candidate-id`继续显示候选与真实来源时码；`.r5-note`只替换既有标题/详情文本，不插入新面板。详情使用事实语言（节拍、用途、上下文、事件/锚数量、复核状态、时长偏离），不显示技术等级或供应商。
- 历史/手动候选缺字段时显示“无完整自动证据快照”，不以默认值冒充已分析。

## 时间线标记语义

- V49 `.r5-anchor`静态伪元素写“差异”，但当前生产桥将该节点作为候选预览播放头移动。
- 本阶段不新增第二时间线标记；给该节点加 `data-clip-playhead`，运行时限定样式把标签改为“预览”，并设置可访问名称“当前预览位置”。
- 这是一项 Product Spec CLIP-024 驱动的受控文案偏离：避免把播放位置伪装成字幕差异证据。位置、颜色、尺寸和时间线结构不变。

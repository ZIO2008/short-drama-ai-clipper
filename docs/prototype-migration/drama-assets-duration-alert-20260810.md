# 原型迁移卡：剧目资产时长异常提示（2026-08-10）

## 原型来源

- 原型版本与路径：`design/open-design/v2026-07-30-open-design-final/short-drama-material-studio.html`
- 目标工具入口：剧目工作区 -> 剧目资产；`DramaAssetsPage.tsx`
- 固定视口与缩放：`1440 x 900`、`1280 x 720`，Windows 100% 缩放。

## 迁移分类

- 分类：屏内受控偏离。
- 已继承外壳：现有剧目资产表的七列、工具栏顺序、表头、内层 `.asset-table-wrap` 滚动和行操作区。
- 偏离原因：原型没有“有效媒体时长异常”这一真实资产质量状态；用户明确要求补充提示与人工忽略。

## 原型边界

- 不改变表格列数、工具栏顺序、页面滚动归属、视频查看、重新定位、删除剧集或剧本资产结构。
- 仅在既有“状态”单元追加 `时长异常 · X.XX 秒` badge，并在既有“操作”单元追加 `忽略提示`。
- 仅当有效媒体时长大于 `0` 且小于 `10` 秒、且用户未忽略时显示。
- 忽略只持久化该集的应用内提示；不删除、移动、改写视频，也不影响 OCR、ASR、字幕导入、切片或任务。

## 验收记录

- 静态结构：保留七列表和内层滚动边界。
- 真实数据：第 48 集 `1.40 秒` 显示提示，忽略后只消除该行提示并更新异常计数。
- 异步与失败：非短时长集拒绝忽略请求；已忽略状态重启后保持。
- 视觉验收：待本轮本地 Electron 构建后按固定视口复核。

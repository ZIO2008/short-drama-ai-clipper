1. 报告渲染独立模块，加载前保存原型完整结果列头模板，按原有5列填入真实结果，保留双层结果表头及滚动容器。

4. 以成功、部分失败、取消/未输出、无批次、加载、读取失败、删除候选、长路径/长结果及旧记录缺信息状态做独立双视口对照，再验证真实后端、统计、过滤与操作。静态或模拟IPC画面对照不冒充真实后端验收。

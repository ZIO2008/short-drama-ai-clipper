# 原剧切片导出配置：目录字段变更记录（2026-10-11）

2026-10-18 当前执行覆盖：用户恢复第一项文件命名配置，已在 0.1.103 独立实现并安装，用户验收待反馈；字段落点及双视口证据见 `prototype-migration/export-naming-20261017.md`。字幕方式仍暂缓，以下旧裁决中的“命名暂缓”仅记沿革，不能覆盖本次执行。

## 已核对的现状

- 当前 `#exportModal` 已提供质量模式、码率或目标大小、帧率、输出目录和包装；`OriginalClipPoolReportRuntimeBridge.ts` 从这些控件创建导出配置，调用真实预检与批次启动。
- 同一桥目前固定 `namingPattern=clip_{episode}_{candidate}`、`subtitleStrategy=none`、`conflictStrategy=append`。因此操作者无法在本次导出前修改命名或字幕方式。
- `ClipExportConfig`、预检与任务快照已接受命名和 `none / soft / burn` 字幕策略。冲突策略的实际合同只有 `append`，即同名自动追加编号；当前没有可安全选择的覆盖模式。
- 现有“设置 → 导出默认值”只保存目录、质量、帧率等默认值；它不能代替本次导出前的配置。
- 当前完整 V49 HTML 的 `#exportModal` 没有命名和字幕控件。增加控件会改变该弹窗，属于已记录的原型偏离。此前候选池迁移卡还提出显式选择候选，但用户已跳过该页面分支；本次不把候选选择并入导出配置任务。

## 推荐的单屏改动

只在现有 `#exportModal .modal-body` 的质量/FPS 与包装区之间增加一组紧凑字段：

1. “文件命名”输入框，默认 `clip_{episode}_{candidate}`，允许现有后端认可的命名规则；格式错误原位提示，不启动预检。
2. “字幕方式”选择框：不附字幕、软字幕、烧录字幕。选后仍由主进程预检查验候选字幕证据，缺失时保留弹窗并说明原因。
3. “同名文件”只读说明：自动追加编号。当前合同不提供覆盖选项。

质量、帧率、目录、包装与原有按钮语义保持。弹窗高度可能增加，使用弹窗内部滚动；候选池行、全选逻辑、完成报告和工作台不在本轮改动范围内。

## 与另一落点的取舍

把这些字段放在“设置 → 导出默认值”只能影响以后任务，不能满足 `CLIP-005` 的“确认候选后、导出前配置”。因此它可作为以后可选的默认值功能，本次不能单独承担需求。

## 分步交付与完成标准

1. **页面裁决**：用户认可上述弹窗字段和只读同名说明。完成标准是明确获准偏离静态 V49，不推断为候选池或报告整页迁移。
2. **弹窗结构**：在运行时已使用的 V49 模态内增加三个位置固定的字段/说明，先完成 1440×900 与 1280×720 的静态和 Electron 对照。完成标准是控件可见、可键盘访问、内部滚动无截断。
3. **真实配置绑定**：导出桥从控件读取命名和字幕方式，沿现有 IPC 传给预检及批次；同名策略继续固定 `append`。完成标准是预检、任务快照和最终报告记录同一配置；取消、阻断、重试不改写已完成成果。
4. **验证与审查**：运行受影响桥测试、类型检查、构建和隔离 Electron 导出回归，独立两阶段审查通过。完成标准是一次真实导出和一次缺字幕阻断均有证据；不使用正式库或源媒体写入。

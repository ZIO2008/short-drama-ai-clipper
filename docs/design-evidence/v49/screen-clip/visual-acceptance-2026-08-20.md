## 受控差异

1. 真实视频画面、PTS、候选 ID、候选/分集数量和文本来自隔离真实数据，不能也不应复制原型演示值。
2. 媒体不可读状态中，原型使用第 06 集，Electron 使用隔离数据的第 04 集；运行时如实显示候选可用性，不伪造演示候选。
3. 原型演示的倍速为 `0.75× / 1× / 1.25× / 1.5×`；运行时按 `CLIP-045` 保持 `0.5× / 1× / 1.5× / 2×`。这是既有真实行为合同优先于静态演示脚本的受控偏离。

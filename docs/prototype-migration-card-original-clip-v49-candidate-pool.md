## 当前事实与缺口

- 已真实具备：按集筛选/搜索/20 行窗口、100×50 压力、删除保护、已确认门禁、目录选择、质量/FPS/包装、批次进度/取消/重试、FFmpeg 验证与成果登记。

- 当前桥固定 `namingPattern='clip_{episode}_{candidate}'`、`subtitleStrategy='none'`、`conflictStrategy='append'`，尽管服务合同已支持命名和字幕策略，并将安全的同名追加编号作为当前冲突合同。
- 这对应 Phase 22 的 P22-02 未决页面策略；不修改页面则核心服务可用，但 CLIP-005 的用户可配置闭环不完整。

## 推荐迁移方案

### 候选池

- 在现有 `.clip-candidate-actions` 中增加一个“加入/移出待导出”选择控件，只对 `confirmed` 候选可用。
- 使用内存 `Set<candidateId>`维护显式选择；重复点击只切换，不会产生重复 candidateId。
- 右侧现有 `.clip-board-inspector`复用：将“待导出”数字改为当前显式选择数量；在现有按钮区增加“选择全部已确认 / 清空选择”。
- 切换分集、筛选、搜索或窗口不会丢失已选择的其它分集候选；候选状态变化、删除或刷新后自动移除不再 confirmed 的选择。
- 不新增抽屉、页面或全量 DOM；500 项选择只保存 ID，不渲染 500 个队列行。

### 导出模态

- 在既有 `#exportModal .modal-body` 内复用 `.form-grid/.field/.input/.select`，新增：
  - 导出范围：只读显示“已选择 N 项”；N=0 时禁止预检。
  - 命名规则：默认 `clip_{episode}_{candidate}`，保留 `{episode}` 与 `{candidate}`占位符。
  - 字幕策略：不导出 / 软字幕 / 烧录字幕；选择软字幕或烧录时继续由预检检查每个候选的来源变体。
  - 同名策略：当前安全合同“自动追加编号”，以只读选择项明确呈现，不引入覆盖源文件或覆盖已有成果。
- 质量模式、码率/大小、FPS、输出目录、包装配置和按钮顺序保持 V49 现状。

## 页面影响

- 会改变候选池每行操作区和右侧按钮区的可见控件；会在导出模态中增加一行表单。
- 需要调整候选行最后一列宽度，但不改变三栏候选池结构、列表窗口化、滚动归属或页面级尺寸。
- 导出模态高度可能增加；保持既有 modal 自身滚动，不增加页面滚动。
- 完成报告、原剧切片工作台、成果库、任务中心和其它页面不修改。

## 风险与保护

- 误选风险：必须显式选择，导出前显示数量并再次走真实预检；不默认导出全部 confirmed。
- 状态漂移：预检和批次抢占仍在 Main 进程再次验证 confirmed + current published snapshot。
- 重复风险：Renderer 使用 Set，Main schema 和 beginBatch 继续拒绝重复 ID。
- 文件风险：同名只允许追加编号；不提供覆盖，源片和既有成果不会被改写。
- 字幕风险：没有候选字幕变体时预检阻断，不回退原字幕或伪造字幕。
